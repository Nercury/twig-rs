# Benchmarks

[criterion](https://docs.rs/criterion) benchmarks of the engine, over the scenarios in `scenarios/`:

| bench | measures |
|---|---|
| `compile` | `Environment::compile_source()` of every template of a scenario: lexing, parsing, node visitors, code generation |
| `render` | `Environment::render()` of a scenario's `index.twig` with its context, templates already loaded |

| scenario | exercises |
|---|---|
| `loops` | nested `for` with `loop.*`, `else`, conditionals, `set` inside loops (100 rows x 10 cells) |
| `inheritance` | three-level `extends`, `parent()`, `include ... with ... only` in a loop |
| `macros` | `import`/`from`, macro calls with defaults and hash arguments, `_self` calls inside macros |
| `escaping` | auto-escaping and the `html`, `js`, `url`, `html_attr`, `css` strategies over HTML, quotes and UTF-8 |
| `filters` | string, number, array and arrow-function filters (`title`, `number_format`, `round`, `sort`, `map`, `reduce`, ...) |
| `dates` | the `date` filter with timezones and `date_modify` |

```bash
cargo bench --bench '*'                              # everything
cargo bench --bench render -- inheritance            # one bench, filtered by name
cargo bench --bench '*' -- --save-baseline before    # compare over time: ... then --baseline before
cargo test --bench '*'                               # run each benchmark once as a test
```

`--bench '*'` selects the benchmark targets only: a plain `cargo bench` also runs the library's libtest harness, which
rejects criterion's options such as `--save-baseline`. Estimates are written to
`target/criterion/<bench>/<scenario>/new/estimates.json`; criterion is built without its `plotters` feature, so it
writes the HTML report (`target/criterion/report/index.html`) only when gnuplot is installed.

Each scenario directory holds its templates (`*.twig`, the entry point is `index.twig`) and its context
(`data.json`, decoded like PHP's `json_decode($json, true)`; generated by `research/benchmarks/gen_data.py`). The
environment uses Twig's default options with the `UTC` timezone. `research/benchmarks/` runs the same scenarios on
PHP Twig for the comparison in its README; `TWIG_BENCH_DUMP=<dir> cargo bench --bench render` writes the rendered
outputs so that they can be compared with PHP's.
