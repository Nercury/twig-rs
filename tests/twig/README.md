# Upstream Twig test data

- `Fixtures/` is a verbatim copy of `tests/Fixtures` from twigphp/Twig v3.31.1 (BSD-3-Clause, see `LICENSE` in
  this directory). Do not edit these files; re-vendor them when the target in `reference/target.md` changes.
- `oracle-corpus.json` is generated by `research/php-oracle/tools/export-corpus.php`. It holds PHP's parse of
  every fixture, the actual PHP results per DATA/EXPECT case, typed trees of the evaluated `--DATA--`/`--CONFIG--`
  values and the PHP state (default timezone, date/number formats) at render time.
